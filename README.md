## الفكرة في سطور
يلصق المستخدم صورة المنشور أو نصه، فتستخرج الأداة ما فيه من آيات وأحاديث، وتطابق كل نص مع المصحف بثماني روايات ومع قاعدة أحكام موثقة من كتب أهل العلم، وتعرض لكل نص بطاقة بإحدى الحالات: «وُجد بحكم منقول»، أو «وُجد بلفظ مختلف» مع النصين متقابلين، أو «لم يُعثر على مرجع، يُحال إلى مختص».

**المبدأ الحاكم:** النموذج لا يُصدر حكماً على حديث أبداً؛ دوره الاستخراج والمطابقة والصياغة، ونقل أقوال أهل العلم كما هي.

## محتوى المستودع
كل الكود في مجلد [`musnid-starter/`](musnid-starter/):
- `public/index.html`: الواجهة.
- `netlify/functions/analyze.js`: دالة التحليل والمطابقة.
- `lib/quran.js` و`data/quran.json.gz`: مطابقة القرآن بالروايات الثماني.
- `data/verdicts.json`: قاعدة الأحكام الموثقة.
- `data/testset.json`: مجموعة الاختبار (منشورات مرقّمة P01–P24، دون صورها).
- `docs/`: نتائج الاختبار ومقارنة النماذج ومقارنة مصادر النص القرآني.
