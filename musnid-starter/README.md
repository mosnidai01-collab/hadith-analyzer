# مُسنِد

أداة تتحقق من الآيات والأحاديث والأقوال المنسوبة في المنشورات المتداولة (مسار 04، تحدي الذكاء الاصطناعي 2026).

**المبدأ الحاكم:** النموذج يستخرج النص ويقسّمه ويصنّفه فقط. الأحكام تُنقل حرفياً من `data/verdicts.json` منسوبةً إلى قائلها، ولا يصدر النموذج حكماً.

## البنية
- `public/index.html`: الواجهة (نص أو صورة، وبطاقات التحقق).
- `netlify/functions/analyze.js`: الاستخراج بالنموذج ثم المطابقة مع قاعدة الأحكام.
- `data/verdicts.json`: قاعدة الأحكام الموثقة (v0.6). `data/testset.json`: مجموعة الاختبار (v0.5).

## النشر على Netlify
1. ارفع المجلد إلى مستودع GitHub عام.
2. في Netlify: Add new site ← Import from Git ← اختر المستودع (الإعدادات تُقرأ من `netlify.toml`).
3. Site configuration ← Environment variables ← أضف `ANTHROPIC_API_KEY` (المفتاح لا يوضع في الكود أبداً).
4. أعد النشر (Deploys ← Trigger deploy)، ثم افتح الرابط.

## إن تجاوز الطلب المهلة (10 ثوانٍ)
أضف متغير البيئة `MODEL=claude-haiku-4-5-20251001` وأعد النشر.

## حالة النسخة
- تعمل: قراءة الصورة/النص، التقسيم والتصنيف، مطابقة الأحاديث والأقوال مع القاعدة، حالات البطاقة، قاعدة ثقة القراءة (حدّها 0.6 مؤقت).
- لم تُبنَ بعد: مطابقة الآيات بالروايات الثماني (يوم التحدي الأول).

## المصادر والتراخيص
- الأحكام: كتب الألباني وغيرها عبر المكتبة الشاملة، وحكم الدرر السنية منسوباً إليها مع الرابط. التفاصيل في `data/verdicts.json` (حقل `sources`).
- نصوص القرآن (لاحقاً): مجمع الملك فهد لطباعة المصحف الشريف.
