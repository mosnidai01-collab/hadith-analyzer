# مُسنِد AI

أداة تتحقق من الآيات والأحاديث والأقوال المنسوبة في المنشورات المتداولة (مسار 04، تحدي الذكاء الاصطناعي 2026).

**المبدأ الحاكم:** النموذج يستخرج النص ويقسّمه ويصنّفه فقط. الأحكام تُنقل حرفياً منسوبةً إلى قائلها، ولا يصدر النموذج حكماً. مصادرها على طبقتين:
1. **قاعدة الأحكام الموثقة** `data/verdicts.json`: راجعها صاحب المشروع على المصادر في المكتبة الشاملة.
2. **الموسوعة الحديثية بالدرر السنية** عبر واجهتها الرسمية (`dorar.net/dorar_api.json`، انظر [dorar.net/article/389](https://dorar.net/article/389)): تُستعلم حيّةً لما لم يوجد في القاعدة، ولا تُخزَّن نتائجها، وتُعرض الألفاظ المطابقة وحدها مع وسم أنها منقولة بواسطة ولم تُراجَع أصولها. تُعطَّل بمتغير البيئة `DORAR_ENABLED=0`.

## البنية
- `public/index.html`: الواجهة (نص أو صورة، وبطاقات التحقق).
- `netlify/functions/analyze.js`: الاستخراج بالنموذج (Google Gemini) ثم المطابقة مع قاعدة الأحكام، ثم البحث في الموسوعة الحديثية لما لم يوجد.
- `data/verdicts.json`: قاعدة الأحكام الموثقة (v0.6). `data/testset.json`: مجموعة الاختبار (v0.5).

## النشر على Netlify
1. ارفع المجلد إلى مستودع GitHub عام.
2. في Netlify: Add new site ← Import from Git ← اختر المستودع (الإعدادات تُقرأ من `netlify.toml`).
3. Site configuration ← Environment variables ← أضف `GEMINI_API_KEY` (المفتاح لا يوضع في الكود أبداً).
4. أعد النشر (Deploys ← Trigger deploy)، ثم افتح الرابط.

## إن تجاوز الطلب المهلة (10 ثوانٍ)
يمكن ضبط `GEMINI_MODEL` (نماذج مفصولة بفواصل تُجرَّب بالترتيب) و`TIME_BUDGET_MS` و`TOTAL_BUDGET_MS`.

## حالة النسخة
- تعمل: قراءة الصورة/النص، التقسيم والتصنيف، مطابقة الأحاديث والأقوال مع القاعدة، حالات البطاقة، قاعدة ثقة القراءة (حدّها 0.6 مؤقت).
- لم تُبنَ بعد: مطابقة الآيات بالروايات الثماني (يوم التحدي الأول).

## المصادر والتراخيص
- الأحكام: كتب الألباني وغيرها عبر المكتبة الشاملة، وما يأتي من الموسوعة الحديثية بالدرر السنية يُعرض منسوباً إليها مع رابط البحث فيها. التفاصيل في `data/verdicts.json` (حقل `sources`).
- نصوص القرآن (لاحقاً): مجمع الملك فهد لطباعة المصحف الشريف.
